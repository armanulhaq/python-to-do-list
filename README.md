# To-Do App

## Description
The To-Do App is a web application built using Streamlit that allows users to manage their tasks easily. Users can add new tasks, view existing ones, and remove completed tasks. The tasks are stored in a text file, ensuring that they persist between sessions.

## Features
- Add new tasks to your to-do list.
- View all existing tasks.
- Remove tasks when completed.
- Simple and user-friendly interface.

## Technologies Used
- Python
- Streamlit

## Installation

1. Clone the repository:
```bash
   git clone https://github.com/armanulahq/python-to-do-list.git
   cd todo-app
```
2. Create a virtual environment:
```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
```
3. Install the required packages:
```bash
pip install streamlit
```
4. Run the application:
```bash
streamlit run app.py
